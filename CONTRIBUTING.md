**ภาษาไทย:** ขอบคุณที่สนใจมีส่วนร่วมในโปรเจกต์นี้!

## How to Contribute

### Reporting Bugs

If you find a bug, please create an issue with:
- Clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
- Your environment (AWS region, Kubernetes version, etc.)

### Suggesting Enhancements

We welcome suggestions for:
- New examples or tutorials
- Improvements to existing documentation
- Additional best practices
- Support for new tools or services

### Pull Requests

1. **Fork the repository**
2. **Create a feature branch**
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Make your changes**
   - Follow existing code style
   - Update documentation if needed
   - Add examples if applicable
4. **Test your changes**
5. **Commit your changes**
   ```bash
   git commit -m "Add amazing feature"
   ```
6. **Push to your fork**
   ```bash
   git push origin feature/amazing-feature
   ```
7. **Open a Pull Request**

## Guidelines

### Documentation Style

- Use clear, concise language
- Provide both English and Thai translations where possible
- Include code examples
- Add comments for complex configurations

### Code Style

- Follow Kubernetes manifest best practices
- Use meaningful resource names
- Include resource limits and requests
- Add labels and annotations

### Examples

When adding new examples:
- Include a comprehensive README
- Provide step-by-step instructions
- Test thoroughly before submitting
- Include cleanup instructions
- Document costs where applicable

## Community

- Be respectful and inclusive
- Help others learn
- Share your experiences
- Give constructive feedback

## Questions?

Feel free to open an issue for any questions about contributing!
